     Plan: Login and Logout (Step 03)

     Context

     Spendly has a registration flow but no working authentication. The /login
     route renders a form but does not handle POST. The /logout route returns a
     placeholder string. This plan wires up both routes using Flask's session,
     adds a DB helper to look up users by email, and updates the login template
     to use the flash message pattern already established by the registration
     flow.

     ---
     Step 3 — app.py: upgrade login() route (lines 57-59)

     Replace the stub with a full GET/POST handler:

     @app.route("/login", methods=["GET", "POST"])
     def login():
         if request.method == "GET":
             return render_template("login.html")

         if request.method == "POST":
             email = request.form.get("email", "").strip()
             password = request.form.get("password", "")

             if not email or not password:
                 flash("All fields are required.", "error")
                 return render_template("login.html")

             user = get_user_by_email(email)
             if user is None or not check_password_hash(user["password_hash"],
     password):
                 flash("Invalid email or password.", "error")
                 return render_template("login.html")

             session["user_id"] = user["id"]
             session["user_name"] = user["name"]
             return redirect(url_for("expenses"))

         abort(405)

     Key rules followed:
     - Generic failure message — never reveals whether email exists
     - Only user_id and user_name stored in session
     - Redirects to url_for("expenses") on success (stub route already exists)

     ---
     Step 4 — app.py: upgrade logout() route (lines 76-78)

     Replace placeholder string return with:

     @app.route("/logout")
     def logout():
         session.clear()
         return redirect(url_for("landing"))

     ---
     Step 5 — templates/login.html: fix flash messages and form action

     Change 1 — lines 16-18: Replace the {% if error %} block with the standard
     flash pattern used in register.html:

     {% with messages = get_flashed_messages(with_categories=true) %}
       {% for category, message in messages %}
         <div class="auth-error">{{ message }}</div>
       {% endfor %}
     {% endwith %}

     Change 2 — line 20: Change hardcoded form action to dynamic URL:
     <!-- before -->
     <form method="POST" action="/login">
     <!-- after -->
     <form method="POST" action="{{ url_for('login') }}">
