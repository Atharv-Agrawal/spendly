     Plan: Database Setup (Step 1)

     Context

     Spendly's database/db.py is a stub with no implementation. All future
     features (auth, expenses) depend on a working SQLite layer. This plan
     implements the three required functions and wires up startup initialization
      in app.py, exactly as specified in .claude/specs/01-database-setup.md.

     ---
     Files to Change

     - database/db.py — implement get_db(), init_db(), seed_db()
     - app.py — add imports and call init_db() / seed_db() at startup

     ---
     Implementation

     1. database/db.py

     Imports needed:
     import sqlite3
     import os
     from werkzeug.security import generate_password_hash

     get_db()
     - Open spendly.db in the project root (os.path.join(os.path.dirname(...), 
     '..', 'spendly.db') or use app context — since this module has no Flask
     dependency, resolve path relative to __file__)
     - Set conn.row_factory = sqlite3.Row
     - Execute PRAGMA foreign_keys = ON
     - Return conn

     init_db()
     - Call get_db(), create both tables with CREATE TABLE IF NOT EXISTS:

     CREATE TABLE IF NOT EXISTS users (
         id           INTEGER PRIMARY KEY AUTOINCREMENT,
         name         TEXT    NOT NULL,
         email        TEXT    UNIQUE NOT NULL,
         password_hash TEXT   NOT NULL,
         created_at   TEXT    DEFAULT (datetime('now'))
     );

     CREATE TABLE IF NOT EXISTS expenses (
         id          INTEGER PRIMARY KEY AUTOINCREMENT,
         user_id     INTEGER NOT NULL REFERENCES users(id),
         amount      REAL    NOT NULL,
         category    TEXT    NOT NULL,
         date        TEXT    NOT NULL,
         description TEXT,
         created_at  TEXT    DEFAULT (datetime('now'))
     );
     - Commit and close connection

     seed_db()
     - Open connection via get_db()
     - Check SELECT COUNT(*) FROM users — if > 0, return early
     - Insert demo user: name="Demo User", email="demo@spendly.com", password
     hashed from "demo123"
     - Get the inserted user_id via cursor.lastrowid
     - Insert 8 expenses (all parameterized), spread across May 2026, covering
     all 7 categories:

     ---
     2. app.py

     Add after from flask import Flask, render_template:

     from database.db import get_db, init_db, seed_db

     Add before (or after) the routes block, before if __name__ == "__main__"::

     with app.app_context():
         init_db()
         seed_db()

     ---
     Rules (from spec)

     - All SQL uses parameterized queries (? placeholders) — no string
     formatting
     - PRAGMA foreign_keys = ON set on every connection in get_db()
     - amount stored as REAL
     - Passwords hashed with werkzeug.security.generate_password_hash
     - No ORMs

       - SELECT COUNT(DISTINCT category) FROM expenses; → 7

     works)
     5. Test FK enforcement: INSERT INTO expenses (user_id, amount, category,
